# Data

Default mode is deterministic demo data generated by `src.analytics.core.demo_transactions`, saved by `python scripts/run_pipeline.py` to `data/sample/transactions.csv`. It is intentionally small and contains order, customer, product, category, quantity, price, date, and region fields.

The included reproducible acquisition uses the UCI Online Retail dataset: https://archive.ics.uci.edu/dataset/352/online+retail. The downloaded Excel file stays under ignored `data/raw/` and is normalized by `scripts/prepare_uci_data.py` into the project transaction schema. Its fields are InvoiceNo, StockCode, Description, Quantity, InvoiceDate, UnitPrice, CustomerID, and Country; cancellations and missing customer IDs are excluded for customer analytics.
